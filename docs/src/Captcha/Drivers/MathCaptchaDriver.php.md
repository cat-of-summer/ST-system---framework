# MathCaptchaDriver.php
<!-- DOCGEN:END -->

`ST_system\Captcha\Drivers\MathCaptchaDriver` - на картинке пример или уравнение, в поле нужно
ввести ответ. Наследник [TextCaptchaDriver](TextCaptchaDriver.php.md): шрифты, адаптеры GD/Imagick,
искажения, шум, попытки - оттуда.

Имя драйвера - `math`.

| Уровень | Задания | Ответ |
|---------|---------|-------|
| `arithmetic` (по умолчанию) | `14+7=?`, `18-5=?` (результат не меньше нуля), `6×7=?` (множители 2..9); слагаемые 1..20 | значение выражения |
| `equation` | `x+5=12`, `x-3=4`, `4x=28`, `3x+4=19` | x - целое 1..12 |
| `mixed` | на каждую выдачу случайно одно из двух | - |

```php
$captcha = CaptchaManager::math('contacts', ['level' => 'equation']);

Assets::addString($captcha->includeCss(), 'head');
Assets::addString($captcha->includeJs(),  'footer');
echo '<form method="post">'.$captcha->putCaptcha().'<button>Send</button></form>';
```

## Конфигурация

| Ключ | По умолчанию | Назначение |
|------|--------------|------------|
| `level` | `arithmetic` | `arithmetic` / `equation` / `mixed`; другое значение - `InvalidArgumentException` |
| `times` | `×` | знак умножения. Если в ваших шрифтах нет глифа `×`, поставьте `x` (в уравнениях умножение не пишется: `3x`) |
| `width` | `280` | ширина картинки |

Плюс ключи `TextCaptchaDriver` (`fonts`, `height`, `distortion`, `noise`, `lines`, `image`, …);
`length`, `char_pool` и `case_sensitive` здесь не используются.

## Особенности

- Пробелов в тексте на картинке нет: рендер ставит символы с равным шагом, и пробел занял бы
  целую клетку. Минус рисуется дефисом - у `−` (U+2212) покрытие в шрифтах хуже.
- Ответ сравнивается как целое число: пробелы отбрасываются, ведущий `+` и нули не мешают,
  `−` и `–` читаются как минус. Больше шести цифр или посторонние символы - неверный ответ.
- Поле - `inputmode="numeric"` (на телефоне цифровая клавиатура), `maxlength="4"`, плейсхолдер
  `?` для примера и `x =` для уравнения.
- Длину ответа клиент не узнаёт: `length = 1`, поле считается заполненным с первой цифры.
- Текст задания в HTML не попадает - только картинка; ответ - в зашифрованном состоянии на сервере.

> [!warning]
> Пример на картинке распознаётся OCR так же, как текст текстовой капчи, и считается машиной
> тривиально. Это капча того же класса, что `text`: она отсекает простых ботов, а от
> целенаправленной атаки защищает поведенческий слой и лимит попыток.

См. также: [TextCaptchaDriver](TextCaptchaDriver.php.md), `Captcha\Drivers\Image\Adapters`.
