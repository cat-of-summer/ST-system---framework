# ArkanoidCaptchaDriver.php
<!-- DOCGEN:END -->

`ST_system\Captcha\Drivers\Game\Arkanoid\ArkanoidCaptchaDriver` - арканоид. Имя драйвера -
`arkanoid`. Основа и проверка - [GameCaptchaDriver](../GameCaptchaDriver.php.md).

- **Цель:** отбить мяч ракеткой `goal` раз подряд (по умолчанию 2), не уронив его. Кирпичи - по
  seed, все разбитые выкладываются заново; на зачёт они не влияют, но в строке счёта - именно
  разбитые кирпичи. Цель засчитывается при доле осмысленных не ниже 75 %: случайные нажатия иногда
  отбивают мяч дважды.
- **Смерть:** мяч ушёл под ракетку.
- **Осмысленное действие:** новая цель ракетки ближе к мячу, пока он летит вниз. Порог сбора данных - 14 действий за 8 с, коридор осмысленности 65-92 %.
- **Управление:** только ◀ ▶ (стрелки или A/D): зажать - ракетка едет к краю на полной скорости,
  отпустить - останавливается; автоповтор не используется, поэтому без рывков. Любое нажатие на
  старте жизни запускает мяч. На телефоне - пара кнопок ◀ ▶, без большой; палец по полю ракетку
  не ведёт.
- **Поле:** мир высотой 280 единиц растянут на всю игровую зону, ширина - под пропорции холста:
  `280 · w / (h − 20)` (200..1200), у холста 320×200 - 498. Кирпичей в ряду - сколько помещается
  (у 498 - 17), рядов 4.
- **Скорость:** 30 тиков в секунду, мяч - 6 единиц за тик по вертикали, угол отскока зависит от
  точки удара о ракетку.
- **Коды ввода:** 0 - куда вести центр ракетки (значение - x в единицах мира; касание пальцем
  переводится из координат холста). Ракетка едет туда не быстрее 8 единиц за тик, поэтому
  подставить её под мяч мгновенно нельзя. Позиция пальца отправляется не чаще раза за тик.
