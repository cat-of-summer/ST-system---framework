# MemoryCaptchaDriver.php
<!-- DOCGEN:END -->

`ST_system\Captcha\Drivers\Game\Memory\MemoryCaptchaDriver` - Memory: все карточки на несколько секунд
открываются, затем переворачиваются рубашкой вверх - пары нужно находить по памяти. Имя драйвера -
`memory`. Основа и проверка - [GameCaptchaDriver](../GameCaptchaDriver.php.md).

- **Сложность - ключ `level`:**

  | `level` | Пар | Показ | Жизней |
  |---------|-----|-------|--------|
  | `easy` | 6 | 6 с | 5 |
  | `normal` (по умолчанию) | 8 | 5 с | 4 |
  | `hard` | 10 | 4 с | 3 |

- **Цель:** найти все пары уровня за одну жизнь. Цель считается из `level`, ключ `goal` её не меняет.
  Ошибки прошлых жизней остаются в счёте, поэтому для зачёта цели хватает половины точных пар
  (`goal_ratio` 0.5).
- **Ход партии:** расклад тасуется от seed. После кнопки старта карточки волной открываются, над
  ними убывает полоса времени, в строке счёта - "Запомните: N" с секундами; затем все закрываются.
  Открыть карточку - клик; две совпали - пара остаётся открытой; не совпали - обе видны 0,8 с
  (следующий клик закрывает их сразу), жизнь − 1.
- **Смерть:** жизни кончились. Новая жизнь - новый расклад и новый показ.
- **Конец партии:** найдены все пары - ответ форме сразу (`over`). Порога сбора данных нет, иначе
  ответ - по `max_time` (90 с).
- **Лица карточек - ключ `faces`:**
  - `emoji` (по умолчанию) - список `emoji` (по умолчанию 30 штук); на каждую выдачу сервер выбирает
    столько разных, сколько пар;
  - `images` - картинки из `images` с ключами `extensions`, `max_images`, `image` (адаптер:
    `gd`, `imagick`, `auto`) и `quality`, как у [пазла](../Puzzle/PuzzleCaptchaDriver.php.md), через
    [ImageSources](../ImageSources.php.md). Каждая выбранная картинка кадрируется адаптером в
    карточку 126×176 и уходит в браузер data URI.

  Лиц меньше, чем пар, или для картинок нет адаптера - драйвер недоступен (`isAvailable() === false`).
- **Поле:** карточки с пропорциями игральной карты 63 × 88 мм и её скруглением углов; раскладка
  подбирается под холст - число столбцов, при котором карточки крупнее; неполный последний ряд - по
  центру. Раскладка - только вид: симуляция знает карточки по номерам.
- **Рубашка:** как у игральной карты - белое поле по краю, тёмно-красная панель с косой сеткой и
  двойной рамкой, ромбики по углам и овальный медальон с розеткой в центре.
- **Осмысленное действие:** вторая карточка пары; осмысленно, если пара совпала. Наугад совпадает
  примерно 1 из 2 · пар − 1. Коридор осмысленности 25-65 %.
- **Управление:** клик или касание карточки; с клавиатуры - стрелки ведут курсор, пробел или Enter
  открывают карточку.
- **Строка счёта:** найденные пары из всех (на показе - оставшиеся секунды); справа - жизни сердечками.
- **Код ввода:** 0, value - номер карточки.
