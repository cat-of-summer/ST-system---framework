# InvadersCaptchaDriver.php
<!-- DOCGEN:END -->

`ST_system\Captcha\Drivers\Game\Invaders\InvadersCaptchaDriver` - Space Invaders: корабль внизу
стреляет вверх по строю пришельцев. Имя драйвера - `invaders`. Основа и проверка -
[GameCaptchaDriver](../GameCaptchaDriver.php.md).

- **Цель:** сбить `goal` пришельцев (по умолчанию 3) за одну жизнь.
- **Смерть:** бомба попала в корабль или строй спустился до линии корабля. Первые 2 секунды жизни
  пришельцы не стреляют.
- **Поле:** мир высотой 200 единиц, ширина - по пропорциям холста: `200 · w / (h − 20)`
  (160..900), у холста 320×200 - 356.
- **Пришельцы:** волна идёт строем вбок, у края спускается на шаг. Сбили всех - следующая волна:
  в ней на колонку больше (сколько помещается) и рядов до четырёх, строй шагает быстрее; чем меньше
  пришельцев осталось, тем быстрее он идёт. Нижний пришелец случайной колонки бросает бомбу, на
  поле не больше трёх бомб.
- **Осмысленное действие:** выстрел, когда над кораблём есть пришелец, и цель корабля ближе к
  ближайшей колонке пришельцев. Когда над кораблём бомба, манёвры не оцениваются - уклонение тоже
  игра. Порог сбора данных - 16 действий за 8 с, коридор осмысленности 50-80 %.
- **Управление:** ◀ ▶ (стрелки, A/D) - зажал, корабль едет к краю, отпустил - стоп; большая кнопка
  (пробел, Enter) - выстрел. На поле одна своя пуля.
- **Скорость:** корабль - 150 единиц в секунду, своя пуля - 270, бомба - 120.
- **Коды ввода:** 0 - куда вести корабль (значение - x центра), 1 - выстрел.
