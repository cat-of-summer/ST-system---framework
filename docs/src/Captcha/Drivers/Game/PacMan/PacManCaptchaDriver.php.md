# PacManCaptchaDriver.php
<!-- DOCGEN:END -->

`ST_system\Captcha\Drivers\Game\PacMan\PacManCaptchaDriver` - пакман в лабиринте. Имя
драйвера - `pacman`. Основа и проверка - [GameCaptchaDriver](../GameCaptchaDriver.php.md).

- **Цель:** съесть `goal` вишен (по умолчанию 2) за одну жизнь. Вишня появляется не ближе
  `⌊(cols + rows) / 3⌋` клеток от Пакмана по прямой (на 19×11 - 10); если таких нет - в самой
  дальней. Точки - для вида, на зачёт не влияют.
- **Смерть:** встреча с призраком. Два призрака на развилках с вероятностью 1/3 идут к Пакману,
  иначе - наугад, назад не разворачиваются.
- **Лабиринт:** строится из seed под холст. Клетка около 16 px, стороны нечётные:
  `cols = w / 16`, `rows = (h − 20) / 16` (7..41), у холста 320×200 - 19×11. Комнаты на нечётных
  клетках соединены обходом в глубину, затем тупики пробиваются насквозь и добавляется
  несколько петель - от призраков всегда есть куда уйти. Пакман стартует внизу по центру,
  призраки - в верхних углах.
- **Осмысленное действие:** поворот туда, где путь до вишни по лабиринту короче, - сразу или на
  ближайшей развилке по ходу (поворот запоминается). Поворот, которого впереди сделать негде, -
  неосмысленный. Рядом с призраком (ближе трёх клеток) повороты не оцениваются: уходить от него -
  тоже игра. Порог сбора данных и запасного пути: 12 действий за 8 с, доля 65 %.
- **Управление:** крестовина (стрелки/WASD). Поворот запоминается и срабатывает на ближайшей
  развилке. Свайпов и тапов по полю нет.
- **Скорость:** Пакман - 5 клеток в секунду, призраки - 3,3.
- **Коды ввода:** 0..3 - куда свернуть.
