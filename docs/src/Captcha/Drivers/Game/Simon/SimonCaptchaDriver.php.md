# SimonCaptchaDriver.php
<!-- DOCGEN:END -->

`ST_system\Captcha\Drivers\Game\Simon\SimonCaptchaDriver` - Simon: сектора круга загораются по
очереди, последовательность нужно повторить. Имя драйвера - `simon`. Основа и проверка -
[GameCaptchaDriver](../GameCaptchaDriver.php.md).

- **Раунды:** каждый раунд - новая случайная последовательность от seed: в первом 4 шага, в каждом
  следующем на шаг больше (5, 6, …). Показ с каждым раундом быстрее: шаг горит от 0,55 с
  в первом раунде до 0,25 с, пауза между шагами - от 0,3 до 0,15 с.
- **Цель:** повторить `rounds` раундов (по умолчанию 2) за одну жизнь. Цель - верные нажатия за эти
  раунды: при двух раундах 4 + 5 = 9. Она считается из `rounds`, ключ `goal` её не меняет.
- **Конец партии:** повторены все `rounds` раундов - ответ форме сразу (`over`). Порога сбора
  данных нет, иначе ответ - по `max_time` (60 с).
- **Смерть:** неверный сектор или 5 с без нажатия на вводе. Новая жизнь - новая последовательность
  с первого раунда.
- **Поле:** круг из `buttons` секторов (3…6, по умолчанию 4) во всю высоту игровой зоны. Сектор `i`
  - по центру угла −90° + i · 360° / buttons: при четырёх - верх, право, низ, лево. Цвета по
  порядку: зелёный, красный, синий, жёлтый, фиолетовый, бирюзовый.
- **Осмысленное действие:** нажатие на вводе; осмысленно, если сектор верный. Нажатия во время
  показа игра не принимает, и действием они не считаются. Коридор осмысленности 45-85 %: случайные
  нажатия попадают в верный сектор в 1 / buttons случаев.
- **Управление:** клик или касание сектора; с клавиатуры - цифры 1…buttons или стрелки (сектор в
  их стороне круга, при четырёх - ровно верх, право, низ, лево). Когда играют с клавиатуры, на
  секторах появляются их номера.
- **Ступица:** номер раунда, "Смотрите" на показе и "Повторите" на вводе, точки шагов (на показе
  закрашиваются по одной и остаются закрашенными, на вводе - по мере повторения), кольцо оставшегося на ввод времени (к концу краснеет); после раунда - галочка и пробег по кругу, при
  ошибке - крестик, неверный сектор краснеет и круг вздрагивает.
- **Код ввода:** 0, value - номер сектора.
