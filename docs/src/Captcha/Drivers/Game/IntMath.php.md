# IntMath.php
<!-- DOCGEN:END -->

`ST_system\Captcha\Drivers\Game\IntMath` - целочисленная геометрия для игр с физикой в
фиксированной точке (пинбол, гонки). Зеркало `assets/engine/src/imath.js`: обе копии игры считают
одно и то же до бита.

Угол - 256 делений круга: 0 - вправо, 64 - вниз (ось y экрана). Синус и косинус ×1024 (`ONE`)
берутся из прописанной таблицы четверти волны, а не из `sin()`: последний бит у PHP и движков JS
мог бы разойтись.

| PHP | JS | Что делает |
|-----|----|-----------|
| `sin($a)`, `cos($a)` | `isin(a)`, `icos(a)` | ×1024, угол приводится по модулю 256 |
| `sqrt($n)` | `isqrt(n)` | ⌊√n⌋ методом Ньютона в целых |
| `len($x, $y)` | `ilen(x, y)` | длина вектора, вниз |
| `atan2($y, $x)` | `iatan2(y, x)` | угол вектора 0…255: октант и двоичный поиск по таблице |
| `adiff($a, $b)` | `adiff(a, b)` | разница углов b − a в −128…127 |
