# SnakeCaptchaDriver.php
<!-- DOCGEN:END -->

`ST_system\Captcha\Drivers\Game\Snake\SnakeCaptchaDriver` - змейка без стен. Имя
драйвера - `snake`. Основа и проверка - [GameCaptchaDriver](../GameCaptchaDriver.php.md).

- **Цель:** съесть `goal` яблок (по умолчанию 2) за одну жизнь. Яблоко появляется в случайной
  свободной клетке не ближе `⌊(cols + rows) / 4⌋` клеток от головы (на 16×9 - 6); если таких
  нет - в самой дальней.
- **Края:** выход за край - с противоположной стороны. Смерть только о собственный хвост.
- **Осмысленное действие:** поворот, после которого голова ближе к яблоку (с учётом перехода через
  край), чем если ехать прямо. Порог сбора данных и запасного пути: 12 действий за 8 с, доля 60 %.
- **Управление:** стрелки/WASD; на телефоне - крестовина, свайп, тап (поворот к точке касания
  относительно головы).
- **Поле:** клетка около 20 px, сетка - сколько помещается в холст: `cols = w / 20` (8..32),
  `rows = (h − 20) / 20` (6..32). Холст 320×200 даёт 16×9. Сетка вписывается в игровую зону по
  центру.
- **Скорость:** 4,8 клетки в секунду: 24 тика в секунду, шаг раз в 5 тиков - поворот ловится
  точнее, чем шаг.
- **Коды ввода:** 0..3 - направление (вверх, вправо, вниз, влево); разворот назад игнорируется.
