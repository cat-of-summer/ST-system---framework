# MinesweeperCaptchaDriver.php
<!-- DOCGEN:END -->

`ST_system\Captcha\Drivers\Game\Minesweeper\MinesweeperCaptchaDriver` - сапёр: открывать клетки
поля, не наступая на мины, по цифрам соседей. Имя драйвера - `minesweeper`. Основа и проверка -
[GameCaptchaDriver](../GameCaptchaDriver.php.md).

- **Цель:** `goal` безопасных ходов (по умолчанию 6) за одну жизнь. Ход - открытие клетки или
  соседей числа, которое открыло хоть одну клетку; первый клик не в счёт - он всегда наугад.
- **Смерть:** открыть мину. Новая жизнь - новое поле.
- **Поле:** ключи `cols` (5..16, по умолчанию 9), `rows` (4..12, по умолчанию 6) и `mines`
  (по умолчанию 8, не больше трети клеток). На вертикальной игровой зоне стороны меняются местами,
  чтобы длинная сторона шла вниз. Клетка - наибольшая, при которой поле с рамкой в четверть клетки
  помещается в игровую зону.
- **Мины:** раскладываются от seed при первом клике и обходят клетку 3×3 вокруг него, так что
  первый клик всегда открывает область. Клетка без мин вокруг открывается заливкой.
- **Конец партии:** открыто всё поле - ответ форме сразу (`over`), не дожидаясь сбора данных.
- **Осмысленное действие:** первый клик; открыть безопасную клетку рядом с уже открытыми; флажок на
  мину рядом с открытыми; открыть соседей числа без ошибки во флажках. Клик наугад вдали от
  открытого, флажок на пустую клетку и взрыв - нет. Снять флажок - не действие. Порог сбора данных -
  6 действий за 12 с, коридор осмысленности 45-85 %.
- **Управление:** на открытом числе любое действие открывает его соседей, если вокруг стоит столько
  же флажков (открыть очевидно безопасные клетки).
  - Мышь - без зажатия: левая кнопка - открыть клетку (ход на отпускании, над той же клеткой),
    правая - флажок (сразу по нажатию), средняя - открыть соседей числа.
  - Палец: тап - открыть клетку; удержание 0,4 с - флажок, по числу - открыть соседей. Срабатывает
    сразу по истечении времени, палец можно не отрывать; вокруг пальца заполняется кольцо. Увёл
    палец на другую клетку - ни тапа, ни удержания.
  - Клавиатура: стрелки - курсор, пробел или Enter - открыть, F - флажок.
- **Строка счёта:** открытые клетки; справа - сколько мин осталось без флажка.
- **Код ввода:** 0 - открыть клетку, 1 - поставить или снять флажок, 2 - открыть соседей числа;
  value - номер клетки `ряд · cols + столбец`.
