# DinoCaptchaDriver.php
<!-- DOCGEN:END -->

`ST_system\Captcha\Drivers\Game\Dino\DinoCaptchaDriver` - DinoRun: динозавр бежит по ускоряющейся
карте и перепрыгивает препятствия. Имя драйвера - `dino`. Основа и проверка -
[GameCaptchaDriver](../GameCaptchaDriver.php.md).

- **Цель:** перепрыгнуть `goal` препятствий (по умолчанию 3) за одну жизнь.
- **Смерть:** касание препятствия.
- **Поле:** мир высотой 150 единиц во всю игровую зону, ширина - по пропорциям холста:
  `150 · w / (h − 20)` (120..700), у холста 320×200 - 267. Динозавр у левого края.
- **Препятствия:** кактусы четырёх видов (одиночные разной высоты и пара стволов) и, с 6-й секунды
  жизни, низкие птицы - их проходят только прыжком. Промежуток до следующего - от seed, не меньше
  прыжка на текущей скорости с запасом: перепрыгнуть можно всегда, и на экране обычно одно-два
  препятствия.
- **Скорость:** 120 единиц в секунду на старте, каждые 2 с - на 7,5 больше, не выше 240.
- **Хитбоксы:** у динозавра - голова, туловище и ноги отдельно, без пустых углов спрайта и кончика
  хвоста; у кактуса - каждый ствол и пояс его рук, у птицы - туловище без крыльев. Рисунок строится
  по тем же размерам.
- **Осмысленное действие:** прыжок, который перелетает ближайшее препятствие: сервер моделирует
  прыжок на текущей скорости. Прыжок в пустоту, слишком рано или слишком поздно - нет. Порог сбора
  данных - 4 прыжка за 8 с, коридор осмысленности 45-80 %.
- **Управление:** большая кнопка; с клавиатуры - пробел, Enter, стрелка вверх или W. Прыжок только
  с земли, в воздухе нажатия не считаются.
- **Код ввода:** 0 - прыжок.
