# ToolError.php
<!-- DOCGEN:END -->

`namespace ST_system\MCP\Tools`

`ToolError` (`extends \RuntimeException`) — отказ операции, понятный модели:

```php
throw new ToolError("Блок {$id} не найден. Список — vault_tree.", ['id' => $id]);
```

Модель получает текст как есть, результат с `isError`, а данные — в `structuredContent`.
Бросают его там, где модель может исправить вызов или выбрать другой путь: не найдено, нет
прав, неподходящее состояние. Доменные исключения приложения удобно наследовать от него.
Прочие исключения модель видит как «Внутренняя ошибка сервера», и они пишутся в `error_log`.
