## Назначение

`ToolsDoc` — справочник инструментов, собранный из живого сервера. Описания живут в
инструментах и уходят агенту по протоколу, поэтому рукописная копия разъехалась бы с ними.

```php
$doc = new ToolsDoc($dispatcher, ['title' => 'MCP — инструменты', 'note' => 'Собран командой `php run mcp_docs`.']);

$doc->problems();   // string[]: что не описано
$doc->markdown();   // инструкции сервера, затем раздел на инструмент с таблицей параметров
```

`problems()` сообщает о таких недочётах:
- у сервера `instructions` короче `ToolsDoc::MIN_DESCRIPTION` (80 символов);
- у инструмента нет названия (`title` пуст или совпадает с именем) или описание короче 80 символов;
- `inputSchema` не объект;
- у параметра нет `description`;
- обязательный параметр не описан в `properties`.

Удобно держать проверку в тесте приложения (`assertSame([], $doc->problems())`), а markdown
выводить CLI-командой.
