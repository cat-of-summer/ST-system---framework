# PendingStore.php
<!-- DOCGEN:END -->

`namespace ST_system\MCP\State`

`PendingStore` — вопросы сервера клиенту, ждущие ответа. Так ответ попадает из одного
воркера в другой:
1. Воркер, держащий поток, регистрирует вопрос (`expect`) и опрашивает его (`take`).
2. Ответ клиента принимает другой воркер и кладёт его сюда (`answer`).
3. По таймауту вопрос снимается (`forget`).

Ответ на незарегистрированный вопрос отбрасывается: чужая сессия или выдуманный id файлов не
создадут. Id запроса приходит от клиента, поэтому в имя файла попадает только его хэш.
